# Guia do Usuário - Sistema de Inspeções Dinâmicas 📱

Este documento descreve como utilizar as principais funcionalidades do aplicativo, desde a criação de formulários até a exportação de relatórios.

---

## 1. Tela Inicial (Painel de Inspeções)
Ao abrir o aplicativo, você verá o painel principal com três áreas principais:
- **Botões Administrativos:** No topo, para criar novos modelos ou gerenciar configurações.
- **Lista de Inspeções Disponíveis:** Todos os formulários criados aparecem aqui para serem preenchidos.
- **Central de Relatórios:** Botão para acessar o histórico de inspeções realizadas.

---

## 2. Como Criar um Novo Modelo (Administrador)
Se você precisa criar um novo checklist ou formulário de inspeção:
1. Clique em **"Novo Modelo"** no painel superior.
2. Dê um **Título** (ex: Checklist de Empilhadeira) e uma **Descrição**.
3. Escolha se o formulário exige **Assinatura** no final.
4. **Adicione Campos:**
   - Clique no ícone de **"+"**.
   - Defina o rótulo (ex: "Estado dos Pneus").
   - Escolha o tipo de campo (Texto, Múltipla Escolha, Status Certo/Errado, Tabela Dinâmica, etc.).
5. Clique em **"Salvar Modelo"**. O formulário aparecerá instantaneamente na tela inicial para todos.

---

## 3. Como Realizar uma Inspeção (Inspetor)
Para preencher um formulário em campo:
1. Na tela inicial, toque no nome do formulário desejado.
2. Preencha os dados de identificação (Colaborador, Fábrica, Setor).
   - *Dica:* Use a busca rápida por nome ou crachá no campo de colaborador.
3. Responda às perguntas:
   - Os campos de **Status (Certo/Errado)** agora aparecem em linha para facilitar o toque rápido.
   - Use os **Chips de seleção** para marcar opções rapidamente.
4. Se houver **Tabela Dinâmica**, clique em "Adicionar Linha" para inserir itens específicos.
5. Assine no campo designado (se exigido).
6. Clique em **"FINALIZAR E ENVIAR RELATÓRIO"**.

---

## 4. Central de Relatórios e Exportação
Para visualizar ou extrair os dados coletados:
1. Clique em **"Central de Relatórios"** na tela inicial.
2. **Filtros:** Use a barra superior para filtrar por:
   - Modelo específico.
   - Período de data.
   - Busca por texto (nome do colaborador, setor, etc.).
3. **Visualização:** Os cards mostram o nome do colaborador e o setor em destaque. Toque em um card para ver todas as respostas e a assinatura.
4. **Paginação:** O sistema exibe 50 registros por vez. Use as setas no rodapé para navegar.
5. **PDF:** Clique no ícone de PDF (superior direito) para gerar um relatório profissional da página atual. O PDF incluirá o total de registros filtrados.

---

## 5. Dicas Importantes e Solução de Problemas
- **Conexão:** O aplicativo exige internet para salvar os dados e carregar os modelos.
- **Campos Obrigatórios:** Campos com um asterisco vermelho (`*`) devem ser preenchidos, caso contrário o sistema não permitirá o envio.
- **Assinatura:** Se você errar a assinatura, clique no botão "Limpar" para refazer.
- **Instalação:** Ao instalar o arquivo APK, o Android pode pedir autorização para "Fontes Desconhecidas". Isso é normal para aplicativos distribuídos internamente.
